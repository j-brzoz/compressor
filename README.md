# compressor

## About
Project using 'C' language.
## Description
Program which allows users to compress and decompress non-empty files utilising Huffman encoding for compression.
## Usage
In order to use compressor, you need to type *make all* in the terminal while being in project's directory.
### To compress:
Usage: ./bin/comp.out 0 input-file output-file
### To decompress:
Usage: ./bin/comp.out 1 input-file output-file
